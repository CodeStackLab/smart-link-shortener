📖 How to Point Your Custom Domain / Subdomain (DNS Guide)
▶ Click to Show Guide

To make your custom domain or subdomain work, you must point it to this server IP. Follow these steps:

  1. Log in to your Domain Registrar (e.g. GoDaddy, Namecheap, Cloudflare, etc.).
  2. Go to the DNS Management page for your domain.
  3. Add a new A Record with the following details:
    • Type: A
    • Name / Host: @ (for root domain like example.com) OR enter your subdomain prefix (e.g. go, track, or link).
    • Value / Points to: 89.117.51.151
    • TTL: Automatic or 1 hour (3600)
  4. Save the record. It can take anywhere from a few minutes to a few hours for the DNS changes to propagate.
  5. Add your domain/subdomain below. Our Caddy server will automatically install a free Let's Encrypt SSL certificate when the link is first loaded!
⚠️ Cloudflare Users: If your domain is in Cloudflare, make sure to change the Proxy Status from Proxied (Orange Cloud) to DNS Only (Grey Cloud) so SSL generation works correctly.
